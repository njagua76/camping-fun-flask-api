#  Camping Fun Flask API

A RESTful API built with Flask to manage campers, activities, and signups for a fictional summer camp. This project was created from scratch as part of a backend challenge.

---

## 🚀 Features

- Create, read, update campers
- View and delete activities
- Register campers for activities via signups
- Validations for age, time, and relationships


---

## Tech Stack

- Python 3.12
- Flask 3.0
- Flask-SQLAlchemy
- Flask-Migrate
- SQLite
- Postman (for manual testing)
- Pytest (for automated testing)
